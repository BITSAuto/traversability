# Q-010 · Where should datasets and models be stored?

- **Opened:** 2026-10-09 · **Status:** Open (team decision) · **Priority:** medium

Bags, frames, students and ONNX models exist only on one laptop and the Orin
([hardware-and-environment.md](../01-overview/hardware-and-environment.md)).
Collaborators can't reproduce results. Options: a team Drive folder, Git LFS
or Hugging Face Hub for models, a lab NAS.
